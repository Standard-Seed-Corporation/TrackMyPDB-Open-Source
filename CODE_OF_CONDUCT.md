# Code of Conduct

TrackMyPDB adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: we want TrackMyPDB to be a welcoming, harassment-free community for everyone.
Be respectful and constructive, assume good intent, and focus on what is best for the
project and its users. Harassment, discriminatory language and personal attacks are
not acceptable in issues, pull requests or any other project space.
